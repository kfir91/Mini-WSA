Mini WSA

Local links for apps and infra. Prefer http://localhost:8080/ (same hub, so alert Define buttons work). Or open this file from the repo root. Status probes hit localhost.

Applications

  • … :8081 ingest-api Validate events → Kafka Swagger Health
  • … :8080 analytics-service Consume · score · Postgres · query APIs Swagger Health

Analytics APIs

  • … GET /v1/stats/summary All configs
  • GET /v1/stats/summary?configId=14227 Filter by config
  • … GET /v1/events/samples?limit=5 Recent samples
  • samples?category=INJECTION SQL / injection
  • samples?category=XSS XSS events
  • samples?action=DENY Denied only
  • samples?minThreatScore=50 High threat
  • … timeseries?interval=1m 5m 1h Bucketed counts
  • timeseries?interval=5m&configId=14227 Timeseries for one config

Alerts (persisted rules)

Define a rule (POST), then open evaluate to see firing / value / threshold. Metrics: event_count, unique_ips · Windows: 5m, 1h. Optional filters: configId, category.

  • … GET /v1/alerts/evaluate Evaluate all defined rules (JSON)
  • Swagger · defineAlert POST /v1/alerts/define
  • Swagger · evaluateAlerts GET with optional alertId
  • Broad event_count
  • Custom category + config
  • Short window
  • Distinct attackers
  • Stricter unique IPs
